Build a full-stack web application for a Gaming Café focused on SLOT BOOKING, BILLING (INVOICING), and INVENTORY MANAGEMENT.

The app should have THREE ROLE-BASED PANELS:
1. Customer Panel
2. Employee Panel
3. Admin Panel

Use a modern UI (dark gaming theme preferred), responsive design (mobile + desktop), secure authentication, and role-based access control.

------------------------------------------------
1️⃣ CUSTOMER PANEL (ONLINE SLOT BOOKING)
------------------------------------------------

Features:
- User login / signup (mobile number or email)
- Customer dashboard showing:
  - Book Slot button
  - Booking history
  - Active / upcoming bookings

Slot Booking Flow:
- Date selection (calendar view)
- Time selection (available time slots like 10:00 AM – 11:00 AM)
- Duration selection (30 min, 1 hour, 2 hours, etc.)
- Game type selection:
  - PS5
  - PS4
  - PC Gaming
  - Xbox
  - VR
  - Racing Simulator
  - Any custom game added by Admin
- Player count selection
- Auto price calculation based on:
  - Game type
  - Duration
  - Number of players
- Show price before booking
- Confirm booking button

After Booking:
- Generate booking ID
- Show invoice preview
- Save booking as "ONLINE BOOKING"
- Store payment status (Paid / Unpaid / Pay at Store)

------------------------------------------------
2️⃣ EMPLOYEE PANEL (OFFLINE ENTRY + BILLING)
------------------------------------------------

Features:
- Employee login
- Simple dashboard with:
  - Create New Offline Entry
  - Generate Bill
  - Today’s Entries

Offline Customer Entry:
- Select game type
- Select date & start time
- Select duration
- Select player count
- Select snacks/items purchased (from inventory)
- Auto calculate total bill:
  - Game charges
  - Snacks charges
  - Taxes (if any)
- Generate INVOICE
- Mark payment method:
  - Cash
  - UPI
  - Card

Billing System:
- Auto invoice number
- Employee name on invoice
- Date & time on invoice
- Print / download invoice (PDF)
- Save entry as "OFFLINE BOOKING"

Tracking:
- Count how many entries employee made in a day
- Total revenue generated by that employee

------------------------------------------------
3️⃣ ADMIN PANEL (FULL CONTROL SYSTEM)
------------------------------------------------

Dashboard Analytics:
- Total revenue (daily / monthly / all-time)
- Total number of customers visited
- Online bookings count
- Offline bookings count
- Revenue split (online vs offline)
- Employee-wise revenue
- Daily employee entry count

Game & Pricing Management:
- Add / edit / delete game types
- Set price per hour for each game
- Set different prices for peak & non-peak hours
- Enable / disable games temporarily

Inventory Management (VERY IMPORTANT):
- Inventory categories:
  - Chips
  - Kurkure
  - Cold drinks
  - Any custom snacks
- Features:
  - Add new inventory items
  - Set buying price & selling price
  - Set stock quantity
  - Auto reduce stock on billing
  - Low stock alert
  - Inventory usage report

User & Role Management:
- Create users
- Assign roles:
  - Admin
  - Employee
- Enable / disable users
- Restrict access based on role

System Settings:
- Change tax percentage
- Change currency
- Change café name, logo, address
- Set invoice format

------------------------------------------------
TECHNICAL REQUIREMENTS
------------------------------------------------

- Role-based authentication
- Secure backend APIs
- Central database for:
  - Users
  - Bookings
  - Invoices
  - Inventory
  - Employees
- Real-time price calculation
- Error handling & validation
- Clean admin UI with charts & tables

------------------------------------------------

The CORE of this app is:
✔ InvoICING (Billing System)
✔ Inventory Management
✔ Employee Tracking
✔ Online + Offline Booking Integration
